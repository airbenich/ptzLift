REST API Endpoints
Relay behavior
Exclusivity rule: when one relay is pressed/activated, all other relays are set to OFF.
Applies to UP, DOWN, Preset 1, Preset 2 and Preset 3.
GET /status
Returns device status, relay states and last action.
Response keys: deviceId, relayState, preset, healthy, companionConnected, ledState, wifi
GET /wifi/status
Returns current Wi‑Fi mode and network information.
Response keys: mode, connected, ssid, savedSsid, ip
POST /wifi/save
Saves Wi‑Fi credentials and reconnects immediately.
If STA connect fails, device falls back to AP mode.
Body: {"ssid":"...","password":"..."}
POST /relay/toggle
Toggles one action relay state for up/down and pulses preset relays.
Body: {"action":"up|down|preset1|preset2|preset3|stop"}
POST /relay/press
Sets UP or DOWN relay explicitly to ON (press behavior).
Body: {"action":"up|down"}
POST /relay/release
Sets UP or DOWN relay explicitly to OFF (release behavior).
Body: {"action":"up|down"}
POST /preset/press
Sets one preset relay explicitly to ON (hold behavior).
Body: {"action":"preset1|preset2|preset3"}
POST /preset/release
Sets one preset relay explicitly to OFF (release behavior).
Body: {"action":"preset1|preset2|preset3"}
POST /preset/1, /preset/2, /preset/3
Triggers the corresponding preset relay (short pulse).
Body: none
POST /preset/1/store, /preset/2/store, /preset/3/store
Triggers the corresponding preset relay in store mode (6s hold).
Body: none
